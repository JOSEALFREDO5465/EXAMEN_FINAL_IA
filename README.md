Agente Inteligente de Licencias SEGIP Bolivia

Como ejecutar

  python3 main.py

Pruebas

  python3 test_agente.py

Opciones del menu

  1. Iniciar nuevo tramite de licencia
  2. Ver requisitos por tipo de licencia
  3. Ver categorias y costos
  4. Salir

Tipos de tramite

  primera vez, renovacion, duplicado, ascenso gradual,
  ascenso directo, provisional, discapacidad fisica,
  discapacidad auditiva, extranjero residente, homologacion

Costos

  P  Bs. 225      A  Bs. 225      M  Bs. 80
  T  Bs. 80       B  Bs. 225      C  Bs. 225
  JP Bs. 225      JM Bs. 80       DP Bs. 160
  DA Bs. 160
